# КАЮК AI — подготовка к запуску

Этот модуль добавляет персонажа КАЮК в Telegram-группу, не меняя ставки, балансы, профили, слоты или Mini App.

## Что делает

- Обрабатывает текстовые сообщения только в чате из `TELEGRAM_GROUP_CHAT_ID`.
- Учитывает только участников, которые сами включили память командой `/kayuk_optin`.
- Сохраняет только короткие безопасные факты, футбольные предпочтения, темы и общие шутки.
- Не архивирует исходные тексты сообщений. Таблица событий содержит только Telegram update ID для защиты от повторной обработки.
- Может отвечать на прямое обращение; спонтанные реплики ограничены вероятностью и общим интервалом.
- Участник может посмотреть свою память или удалить её.

## Требуемые переменные Vercel

Добавить в Production:

- `OPENAI_API_KEY` — API key платформы OpenAI.
- `KAYUK_AI_MODEL` — необязательно; по умолчанию `gpt-4o-mini`.

Уже используемые проектом переменные должны оставаться без изменений:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_GROUP_CHAT_ID`
- `TELEGRAM_BOT_USERNAME`
- `ADMIN_TELEGRAM_ID`
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`

Не добавлять ключ OpenAI в клиентский код, HTML или GitHub.

## Supabase

После проверки этой ветки вручную выполнить файл `supabase/kayuk-ai-memory.sql` в SQL Editor основного проекта Supabase `kayuk-bet`. Миграция создаёт только три отдельные таблицы с префиксом `kayuk_ai_` и не изменяет существующие таблицы.

## Telegram

Чтобы получать обычные сообщения группы, у бота должен быть отключён Privacy Mode через BotFather: `/setprivacy` → выбрать бота → `Disable`. Если Telegram попросит, удалить бота из группы и добавить снова. Не выдавать боту права администратора без необходимости.

## Первый запуск

1. Добавить `OPENAI_API_KEY` в Vercel Production.
2. Выполнить SQL миграцию в основном Supabase.
3. Проверить, что бот получает обычные сообщения группы.
4. В группе опубликовать уведомление о том, что участники могут добровольно включить AI-память.
5. Каждый желающий пишет `/kayuk_optin`.
6. Администратор пишет `/kayuk_on`.

Команды:

- `/kayuk_privacy` — правила обработки.
- `/kayuk_optin` — добровольно включить память.
- `/kayuk_memory` — посмотреть сохранённые сведения о себе.
- `/kayuk_optout` — удалить свою память и выключить её.
- `/kayuk_off` — выключить персонажа для всей группы (только администратор).

По умолчанию персонаж выключен. Пока SQL миграция и ключ OpenAI не добавлены, работающая версия бота остаётся без изменений.
