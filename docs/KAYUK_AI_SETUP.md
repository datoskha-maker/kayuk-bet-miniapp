# КАЮК AI — подготовка к запуску

Этот модуль добавляет персонажа КАЮК в Telegram-группу, не меняя ставки, балансы, профили, казино, слоты или КАЮК SLICE.

## Что делает

- Обрабатывает входящие текстовые сообщения только в чате из `TELEGRAM_GROUP_CHAT_ID`.
- Учитывает сообщения и игровые данные только участников, которые сами включили участие командой `/kayuk_optin`.
- Может сам решить, на какое входящее сообщение ответить; упоминание бота или reply на его сообщение не требуются.
- Никогда не начинает разговор первым и не отправляет сообщения без входящего сообщения живого участника.
- Сохраняет только короткие безопасные факты, футбольные предпочтения, темы и общие шутки.
- Для opted-in участников читает и анализирует виртуальный баланс, историю и статистику ставок, историю казино/слотов и результаты КАЮК SLICE.
- Игровые данные используются редко — только если конкретная деталь действительно усиливает шутку или ответ. Они доступны модели только как read-only контекст.
- Код аналитики выполняет только SELECT-запросы к таблицам Mini App. Он не меняет ставки, балансы, результаты, профили, транзакции, слоты, игровые очки или награды.
- Не раскрывает точные балансы и подробную историю другого участника.
- Администратор полностью исключён из подколов, насмешек, троллинга и споров; без лести и подхалимства.
- Не архивирует исходные тексты сообщений. Таблица событий содержит только Telegram update ID для защиты от повторной обработки.
- Участник может посмотреть свою сохранённую память или удалить её и прекратить участие.

## Требуемые переменные Vercel

Добавить в Production:

- `OPENAI_API_KEY` — API key платформы OpenAI.
- `KAYUK_AI_MODEL` — необязательно; по умолчанию `gpt-4o-mini`.

Уже используемые проектом переменные должны оставаться без изменений:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_GROUP_CHAT_ID`
- `TELEGRAM_BOT_USERNAME`
- `ADMIN_TELEGRAM_ID`
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`

Не добавлять ключ OpenAI в клиентский код, HTML или GitHub.

## Supabase

После проверки этой ветки вручную выполнить файл `supabase/kayuk-ai-memory.sql` в SQL Editor основного проекта Supabase `kayuk-bet`. Миграция создаёт только три отдельные таблицы с префиксом `kayuk_ai_` и не изменяет существующие таблицы Mini App.

## Telegram

Чтобы получать обычные сообщения группы, у бота должен быть отключён Privacy Mode через BotFather: `/setprivacy` → выбрать бота → `Disable`. Если Telegram попросит, удалить бота из группы и добавить снова. Не выдавать боту права администратора без необходимости.

## Первый запуск

1. Добавить `OPENAI_API_KEY` в Vercel Production.
2. Выполнить SQL миграцию в основном Supabase.
3. Проверить, что бот получает обычные сообщения группы.
4. В группе опубликовать уведомление о добровольном участии и анализе игровых данных.
5. Каждый желающий пишет `/kayuk_optin`. Команда включает анализ его сообщений, безопасную память и read-only анализ его игровых данных.
6. Администратор пишет `/kayuk_on`.

Команды:

- `/kayuk_privacy` — правила обработки и перечень анализируемых игровых данных.
- `/kayuk_optin` — добровольно включить анализ и память.
- `/kayuk_memory` — посмотреть сохранённые сведения о себе.
- `/kayuk_optout` — удалить свою память и выключить анализ.
- `/kayuk_off` — выключить персонажа для всей группы (только администратор).

По умолчанию персонаж выключен. Пока SQL миграция и ключ OpenAI не добавлены, работающая версия бота остаётся без изменений.
